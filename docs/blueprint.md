# **App Name**: GratitudeFlow

## Core Features:

- Reflection Capture: Capture user's daily reflections and feelings with a timestamped record.
- Personalized Gratitude Generation: AI tool generates personalized gratitude messages based on user's input to foster a positive mindset. 
- Message Display: Display the timestamped reflections and corresponding gratitude messages.
- Emotional Tracking: Enable users to track their emotional journey over time, highlighting patterns and progress.

## Style Guidelines:

- Primary color: Muted Coral (#F08080) evokes warmth and compassion, supporting the user's emotional exploration.
- Background color: Pale Peach (#F9E7E7), very light, provides a gentle, calming backdrop.
- Accent color: Soft Gold (#D4AF37), creates subtle contrast with a color linked to self-worth and abundance.
- Calming and flowing fonts
- Use gentle, flowing icons related to feelings, emotions and states of gratitude.
- Subtle animations for a sense of peace.
